# AGI Weekly

![](https://cdn.zhangferry.com/Images/x-cover.png)

AGI 摸鱼周报是一份每周更新的 AI 技术周报，关注 Coding Agent、工程基础设施、安全治理、质量评测与开源社区动态。

每周发布新一期。每篇周报会筛选值得继续阅读的文章和项目，保留原文链接，并给出简短的阅读提示。
